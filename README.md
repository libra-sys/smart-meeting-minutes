# 智能会议纪要生成器

> Smart Meeting Minutes — 议题拆分 · 决议提取 · 行动项追踪 · 分歧识别

[![Version](https://img.shields.io/badge/version-v1.0.0-blue)]()
[![Platform](https://img.shields.io/badge/platform-WorkBuddy-purple)]()

## 功能概述

面向企业团队的会议效率工具。上传会议录音转录文本或笔记，自动识别会议类型、拆分议题、提取决议和行动项（含负责人与截止时间）、标注关键分歧点，生成规范的结构化纪要。

## 核心功能

| 功能 | 说明 |
|------|------|
| **智能解析** | 自动识别 4 种会议类型（项目例会/管理层/评审/头脑风暴），提取参与者/日期 |
| **议题拆解** | 3-7 个独立议题，每个含标题+讨论摘要+发言人立场 |
| **行动项提取** | 任务+负责人+截止时间+优先级（高/中/低），责任人未知标注"待确认"不猜测 |
| **分歧标记** | 识别争议点，标注正反方观点和解决状态 |
| **多格式输出** | 按会议类型自适应纪要格式，含议题摘要/决议/行动项追踪表/分歧表/下次会议 |
| **质量校验** | 10 项格式检查脚本，责任人缺失告警 |

## 支持会议类型

| 类型 | 输出侧重 |
|------|----------|
| 项目例会 | 进度更新、阻塞项、行动项追踪 |
| 管理层会议 | 战略决策、资源分配、预算审批 |
| 技术评审 | 方案对比、技术分歧、待确认事项 |
| 头脑风暴 | 创意汇总、可行性评估、后续调研 |

## 技术特点

- **多说话人识别** — 代词上下文还原
- **隐含行动项捕捉** — 识别"我回去查一下"等承诺
- **不凭空捏造** — 不添加原文没有的内容
- **责任人标注** — 无法确认标注"待确认"不猜测
- **10 项格式校验** — validate.sh 自动化验证

## 触发方式

```
会议纪要 [转录文本]
帮我整理会议记录
会议待办 [会议内容]
```
