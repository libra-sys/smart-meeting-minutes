# 示例输入：项目例会会议记录

**原始会议转录文本（2024-03-14，项目组周例会）**

---

2024年3月14日，下午2点，在会议室B301，项目组例会正式开始。

参与者：张伟（项目经理）、李娜（前端负责人）、王强（后端负责人）、陈晓（测试负责人）、刘洋（产品经理）

**张伟开场**：今天主要讨论三个事情，一是上周行动项回顾，二是本周进度，三是用户验收测试的准备工作。

**进度回顾**：
上周确定的事情：李娜负责修复登录页面的3个bug，王强负责优化接口响应时间到200ms以下，陈晓要出测试计划。
李娜说3个bug已经修完了，但是还有2个新bug是在测试阶段发现的，说这两个影响不大，这周一定搞定。
王强说接口响应时间还没达到目标，目前平均还有380ms，他说主要是数据库查询的问题，需要加索引，他说下周三之前肯定能搞定。
陈晓说测试计划已经写好了，已经发给大家看了，不知道大家有没有看。

**产品更新**：
刘洋说上周和客户开会，客户那边提了几个新需求，主要是报表功能要增加导出Excel的功能，还有就是移动端适配问题。刘洋说这两个需求要评估一下工作量。
张伟说新需求要走正式变更流程，不能随便加，让刘洋整理需求文档，下周一之前发过来。
刘洋同意了。

**UAT准备**：
张伟说用户验收测试计划在4月1号，现在离那时候只有2个半星期了，时间比较紧。
陈晓说测试环境还没准备好，需要王强帮忙部署一下。
王强说这周五之前搞定测试环境部署。
张伟说关于UAT的测试用例，需要刘洋配合整理业务场景，刘洋说没问题，他会在下周五之前给陈晓发过去。
陈晓说收到，她会在收到业务场景之后3天内完成测试用例编写。

**分歧讨论**：
关于移动端适配要不要在这个版本做，张伟认为时间太紧不适合在这个版本加，李娜也表示移动端适配工作量比较大，至少需要2周。但刘洋坚持说客户很在意这个，不做的话验收可能会有问题。最后大家决定下次会议之前让刘洋先跟客户确认一下这个需求的优先级，再做决定。

**会议结束**：张伟总结，今天会议到此结束，下次例会还是下周四下午2点。
